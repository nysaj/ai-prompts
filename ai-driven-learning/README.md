# AI学習ワークフロー

プログラミング学習を効率化するための、再利用可能なAIプロンプト集です。

## 学習フロー

1. 予習ガイド作成
2. 学習中のサポート
3. 演習問題作成
4. コードレビュー
5. チートシート作成
6. 翌日の復習
7. 週次総合演習

## ファイル一覧

| ファイル | 内容 |
|----------|------|
| 01-preview-guide.md | 動画や教材を学習する前に、重要なポイントや注目すべき点を整理するためのプロンプト |
| 02-learning-support.md | 学習中に理解できなかった内容や疑問点を整理・解説してもらうためのプロンプト |
| 03-practice-task.md | 学習内容を定着させるための小さな演習課題を作成するプロンプト |
| 04-code-review.md | 自分で書いたコードをレビューしてもらい、改善点や良い点を確認するプロンプト |
| 05-cheat-sheet.md | 学習内容を短時間で復習できるチートシートを作成するプロンプト |
| 06-next-day-review.md | 前日に学習した内容を効率よく復習するためのプロンプト |
| 07-weekly-practice.md | 1週間の学習内容を組み合わせた総合演習を作成するプロンプト |

## 目的

このディレクトリは、AIを使ってプログラミングの学習をサポートするためのプロンプトを管理しています。

限られた学習時間を効果的に使い、理解を深めながらアウトプットすることを目的としています。
